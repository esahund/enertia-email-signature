# Enertia Email Signature

A small GitHub Pages site for previewing and linking the Enertia email-signature animation.

## Add the GIF

Upload the animation to the repository root with the exact filename `signature.gif`. The page preview and download link use that file, and the stable image URL will be:

`https://esahund.github.io/enertia-email-signature/signature.gif`

The image attached in the conversation could not be uploaded as a binary file through this setup, so the GIF still needs to be added to the repository.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save. GitHub Pages will then publish the page at:

`https://esahund.github.io/enertia-email-signature/`
